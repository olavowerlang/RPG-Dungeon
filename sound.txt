SOUND SESSION - WHAT WAS DONE & WHAT'S LEFT
============================================

WHAT WAS BUILT
--------------
- AudioManager.cs (Assets/Scripts/)
    - Singleton, persists across scenes (DontDestroyOnLoad)
    - Creates its own AudioSources automatically — do NOT add AudioSource manually
    - Every clip has a volume slider (Range 0-1) right below it in the Inspector
    - Attack and dash use dedicated AudioSources with Play() so each new press cuts the previous sound
    - Slime jump capped at 2 simultaneous sounds
    - Auto-wires ALL buttons in ALL scenes to the UI click sound on scene load — no per-button setup needed

- EnemyAmbientSound.cs (Assets/Scripts/)
    - Add to enemy root (Skeleton, Shroom, Slime)
    - Plays idle sounds on random interval when player is within range
    - Globally capped at 2 simultaneous per enemy type so a room full of enemies doesn't become noise
    - Types: Skeleton, Shroom, Slime
    - Static counters reset on scene load (bug fix applied)
    - Uses WaitForSecondsRealtime so counters release correctly even when game is paused (bug fix applied)
    - OnDestroy releases slot if enemy is killed mid-sound (bug fix applied)

- EnemyDeathSound.cs (Assets/Scripts/)
    - Add to any enemy root, drag in a clip — hooks Health.OnDeath automatically

- MusicZone.cs (Assets/Scripts/)
    - Add to a trigger collider in scene to switch music when player enters
    - Zone options: StartArea, Combat, Shop, Boss, Stop

- UIClickSound.cs (Assets/Scripts/) — NOT NEEDED ANYMORE
    - Kept for reference but AudioManager auto-wires all buttons now
