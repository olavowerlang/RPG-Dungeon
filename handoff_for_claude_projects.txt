## 1. MULTIDIRECTIONAL ANIMATION (Player + SkeletonFighter)

The C# code is already done. Both PlayerAnimator.cs and EnemyAnimator.cs already push
DirX (float) and DirY (float) to the Animator every frame, and flip the sprite horizontally
via localScale when moving left.

What's missing is the Unity Animator Controller side:
- Currently, walk/idle/attack states use single directional sprites (left/right only via flip).
- I have sprite sheets with up, down, left, right directions.
- I need to set up 2D Blend Trees (2D Simple Directional) for the Walk (and optionally Idle)
  states, using DirX and DirY as the blend parameters, with one motion per direction.
- The animator scripts already set DirX/DirY correctly — I just need guidance on how to build
  the blend trees in the Unity Animator window, and how to structure the animation clips
  (should each direction be its own clip? how do I slice them from the sprite sheet?).

Affected Animator Controllers:
- Player Animator Controller (used by PlayerAnimator.cs)
- SkeletonFighter Animator Controller (used by EnemyAnimator.cs)

The sprite flip for left/right is already handled in code via localScale, so I may only need
up/down/side directions in the blend tree (3 directions, using flip for the 4th).

## 2. NEW ENEMY SETUP IN UNITY EDITOR

Three new enemies have been fully coded. I need help setting up their prefabs, Animator
Controllers, and Inspector wiring. All three follow the same pattern as the existing
SkeletonFighter enemy.

### Prefab hierarchy pattern (same for all three):
Root GameObject:
  - Rigidbody2D (Collision Detection: Continuous, Freeze Z rotation)
  - Collider2D (CapsuleCollider2D or CircleCollider2D — body trigger OFF, physics ON)
  - Health component
  - GenericEnemyHitEffect component (handles knockback + blink on hit, implements IDamageable)
  - EnemyContactDamage component (deals damage to player on body contact)
  - [Enemy-specific AI script]

  Child "Visual" (holds sprites + Animator):
  - SpriteRenderer
  - Animator
  - [Enemy-specific Animator script]

- IDamageable interface is how hits land. GenericEnemyHitEffect implements it for all new enemies.
- Gold drops use GoldDrop prefab (already exists). Item drops use ItemDrop prefab (already exists).
  Just drag those into the Inspector fields on the Animator scripts.
- LootTable is a ScriptableObject (create via Assets menu > Inventory > Loot Table).
- EnemyContactDamage needs the Player layer set in its playerLayer LayerMask.
- GenericEnemyHitEffect needs a SpriteRenderer somewhere in the children for the blink effect.
